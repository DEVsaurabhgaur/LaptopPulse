System Overview

Silent. Precise. Always On.

LaptopPulse is a lightweight background service that monitors laptop hardware health 24/7. It collects temperature, fan speed, and performance metrics every 60 seconds, stores them in compressed local logs, and uses a rule-based anomaly detector to catch degradation trends 30–60 days before failure. When an anomaly is detected, an AI engine generates a plain-language service report — no jargon, just action.

System Architecture

Four-Layer Design

01

Silent Watcher Daemon

Collects raw sensor data every 60 sec — CPU temp, GPU temp, fan RPM, battery health. Uses < 0.3% CPU.

ALWAYS ON
02

Anomaly Detector

Rule-based + trend analysis engine. Threshold rules for immediate danger + 30/60/90-day trend detection.

ALWAYS ON
03

Log Accumulator

Stores compressed daily JSONL logs. 90-day auto-rotation. ~120KB/month total storage. Zero cloud.

ALWAYS ON
04

AI Report Generator

Fires once on anomaly detection. Aggregates 30 days of logs, calls Claude API, generates HTML report. Then sleeps.

EVENT ONLY
Security Model

Built Safe, Not Bolted On.

AES-256-GCM Encryption

All local log files encrypted at rest. Machine-derived keys — data unreadable if stolen.

Zero-Telemetry Design

No analytics, no crash reports, no data leaves the machine. API keys zeroised from memory after use.

Supply Chain Integrity

Signed executable. SHA-256 hashes with every release. HMAC signatures on every log entry.
