Project Overview

Silent. Precise.
Always On.

LaptopPulse is a lightweight background service that monitors laptop hardware health 24/7. It collects temperature, fan speed, and performance metrics every 60 seconds, stores them in compressed local logs, and uses a rule-based anomaly detector to catch degradation trends 30–60 days before failure. When an anomaly is detected, an AI engine generates a plain-language service report — no jargon, just action.

<0.3% CPU overhead
60s Reading interval
120KB Storage / month
30–60d Failure prediction window
Zero Cloud dependency

System Architecture

Four-Layer Design

Each layer is independently replaceable. The event-driven design means the AI engine — the heaviest component — only fires when needed, then sleeps.

01

Silent Watcher Daemon

Collects raw sensor data every 60 sec — CPU temp, GPU temp, fan RPM, battery health. Uses <0.3% CPU.

ALWAYS ON
02

Anomaly Detector

Rule-based + trend analysis engine. Threshold rules for immediate danger + 30/60/90-day trend detection.

ALWAYS ON
03

Log Accumulator

Stores compressed daily JSONL logs. 90-day auto-rotation. ~120KB/month total storage. Zero cloud.

ALWAYS ON
04

AI Report Generator

Fires once on anomaly detection. Aggregates 30 days of logs, calls Gemini API, generates HTML report. Then sleeps.

EVENT ONLY

Security Model

Built Safe,
Not Bolted On.

AES-256-GCM Encryption

All local log files and configuration data are encrypted at rest using hardware-accelerated AES-256-GCM. Machine-derived keys mean data is bound to the host — unreadable if stolen.

Zero-Telemetry Design

No analytics, no crash reports, no data leaves the machine. API keys are zeroised from memory immediately after use. Privacy is the architecture, not a setting.

Supply Chain Integrity

Executable is signed with a code-signing certificate. SHA-256 hashes are published with every release. HMAC signatures on log entries prevent tampering.

Development Timeline

8-Week Execution

Every phase executed in sequence: Requirements → System Design → Technology Selection → Implementation → Testing → Security Hardening → Deployment → Maintenance. No shortcuts.

01

Foundation

Install Python 3.11, psutil, LibreHardwareMonitor. Write watcher.py — reads CPU/GPU temp + fan RPM. Test on TUF A15. 24 hours of clean log data.

02

Anomaly Detection

Build threshold.py with all 10 core rules. Build trend.py — 7-day baseline + 30-day delta. Unit test every rule with mock data.

03

Storage

Build logger.py — compressed daily JSONL. Build baseline.py — capture first 7-day profile. Build trends_calc.py — rolling averages.

04

Service Shell

Install pywin32 — register as Windows Service. Build tray.py — green/yellow/red icon states. Right-click menu: View Status, View Reports, Settings.

05

AI Engine

Integrate Gemini API. Write prompt templates for each anomaly type. Build html_render.py — dark-themed report output.

06

Edge Cases

Handle edge cases: no NVIDIA GPU, WMI failures. Add AMD GPU support (rocm-smi / WMI fallback). Add offline mode — rule-based report without AI.

07

Packaging

PyInstaller: package into single .exe. Inno Setup: create proper Windows installer. Test install/uninstall on clean Windows 11 VM.

08

Beta Launch

Post on r/hardware, r/india, r/laptops. Post on Twitter/X with demo video. First 100 users: FREE — collect feedback and iterate.
