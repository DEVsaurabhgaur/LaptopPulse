# Assets

Place your icon files here:
- `icon.ico` — Windows application icon (required for PyInstaller build)
- `icon_green.ico` — Tray icon: healthy state
- `icon_yellow.ico` — Tray icon: warning state  
- `icon_red.ico` — Tray icon: critical state
- `screenshot_report.png` — For README (shows AI report output)
- `screenshot_tray.png` — For README (shows system tray icon)
- `demo.gif` — Animated demo (high impact for GitHub)

Icon specs:
- .ico files: 256×256, 128×128, 64×64, 32×32, 16×16 (multi-size ICO)
- Use a dark background with #E8593C accent color for brand consistency
